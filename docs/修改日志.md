# 修改日志

## [1.1.0] - 2026-07-27

### 可观测性

- 网关结构化日志升级为有界异步队列：请求协程不执行 stdout/磁盘 I/O，队列饱和时不中断业务，
  并通过 `dropped_logs_before` 或关闭事件暴露丢弃数。
- 文件日志改用稳定 `gateway.log`，单文件默认上限随业务 JSON 日志增大为 200 MiB，并同时受
  `LOG_MAX_FILE_MB`、`LOG_BACKUP_COUNT` 和 `LOG_RETENTION_DAYS` 约束；启动时兼容清理旧
  `gateway_<pid>.log*`，解决重启后文件永久残留。
  Compose 继续通过 `asr-logs` 命名卷持久化文件日志；`run.sh` 让网关严格 JSON 独占 stdout，
  启动提示、下载器和 vLLM 使用 stderr，并为两条容器日志流配置独立于应用文件的 `json-file`
  大小与文件数轮转。
- JSON 格式化增加有限数值检查、未知对象降级、二进制长度替代、集合/字符串/异常堆栈边界及
  Unicode 控制字符转义；输出 handler 失败后安全停用，不打印包含原字段的 logging traceback。
- 进入 aiohttp 请求中间件且能够形成响应的成功和错误请求回传 `X-Request-ID`；合法客户端 ID
  可透传，否则生成完整 UUID hex，并通过 ContextVar 关联 HTTP、后端分片和 ForcedAligner
  事件。取消和断连按观测状态 499 记录；解析前拒绝或连接已断开时不承诺响应头。
- 请求完成日志在保留字段名、音频大小/时长、分片、语言、结果计数、错误码、状态及耗时等
  摘要的同时，新增 `/chinese_asr` 的 `input_json` 和 `result_json`。输入 Base64 只记录前 64 个
  ASCII 字节，完整长度继续由 `base64_encoded_chars` 表示；结构化业务 JSON 仍受字符串、集合
  和嵌套上限保护。日志因此可能包含热词、来源 URL 与识别正文，部署必须收紧访问和保留周期；
  音频二进制、multipart 文件名和后端 Prompt 仍不落日志。

### 容器

- Dockerfile 兼容仅提供 `python3`/`python3.12` 的 vLLM 基础镜像：构建时探测实际解释器并
  创建 `/usr/local/bin/python`，保证依赖安装、启动脚本和健康检查使用同一 Python 环境。
- 为私有基础镜像预装但依赖不完整的 PyGObject 补齐系统包 `python3-cairo`，继续保留严格
  `pip check`，不通过忽略检查掩盖基础镜像问题。
- Aligner 构建会移除 apt/distutils 遗留的 `blinker 1.4`，再以 `--ignore-installed` 固定覆盖
  `blinker==1.9.0`；发布镜像默认 `INSTALL_ALIGNER=true` 并安装 `qwen-asr==0.0.6`。
- 两个时间戳开关统一默认开启；默认启动会校验 Aligner 依赖并从 ModelScope 检查或下载固定
  revision 权重。仅在定制构建 `INSTALL_ALIGNER=false` 时，运行时必须同步关闭两个时间戳开关。
- Dockerfile 明确执行 `COPY models models`、`COPY tests tests`、`COPY test_data test_data`；
  `.dockerignore` 不再排除这三个目录，发布镜像包含模型、测试代码和验收数据。

### 输入与调度

- 统一默认 `AUDIO_CHUNK_SECONDS=32`、`MAX_AUDIO_SECONDS=2000`、`MAX_UPLOAD_MB=280`、
  `MAX_JSON_BODY_MB=280`；Base64 膨胀使 JSON 接口可承载的原始音频约为 210 MiB。
- `CHUNK_CONCURRENCY=3`、`LONG_CHUNKS_IN_FLIGHT=96`；采用历史 A10 纯 90 秒最高吞吐组合，
  默认同卡 Aligner 和 0～2000 秒真实混合流量仍须重新验收。
- 统一 vLLM 默认：`VLLM_GPU_MEMORY_UTILIZATION=0.85`、`VLLM_MAX_MODEL_LEN=10240`、
  `VLLM_MAX_NUM_BATCHED_TOKENS=10240`、`VLLM_MAX_AUDIO_CLIP_FILESIZE_MB=96`、
  `VLLM_LOAD_FORMAT=safetensors`。

### 语种识别与 ForcedAligner

- `/chinese_asr` 未传 `language` 时保留 Qwen3-ASR 原始自动检测标签，为每个物理分片填写
  `slid`；显式语言支持官方 30 种语言名称或 ISO 代码，不根据文字或文件名猜测。
- 主模型官方能力范围为 30 种语言和 22 种中国方言/口音；方言标签可自动返回，但不承诺
  对全部相近方言做到客观准确区分。
- 新增并默认启用 `Qwen/Qwen3-ForcedAligner-0.6B`，仅从 ModelScope 固定 revision 下载；
  支持 `/chinese_asr` 中文字符/其他语言词级时间戳及按主模型标点聚合的句级结果。
- ForcedAligner 只支持 Chinese、English、Cantonese、French、German、Italian、Japanese、
  Korean、Portuguese、Russian、Spanish。语种为空或不受支持的分片显式跳过对齐但不中断
  ASR：HTTP 200 保留文本、`slid` 和物理边界，`words=[]`，顶层 `message` 列出跳过项；支持
  的其他分片仍执行真实对齐。取消 `DEFAULT_ALIGNER_LANGUAGE=Chinese`，不静默回退中文。
- 全部分片成功对齐时，句级结果继承实际对齐单元语言，跨语种句子的 `slid` 按出现顺序以
  逗号合并；存在跳过分片时禁用句级聚合并显式告警，防止伪造句级时间戳。
- 错误码 1009 保留给 Aligner 推理失败、返回结构异常或句级结果无法可靠映射，不再用于可预判
  的不支持语种。
- 单 A10 同卡默认 `cuda:0/bfloat16/concurrency=1/batch=1`；vLLM 固定默认显存预算为 0.85。
  该能力尚需目标 Linux/CUDA 的 OOM、吞吐和尾延迟验收。
- 主模型自带标点，不使用 CT-Transformer；流式 HTTP 网关和说话人识别仍未实现。

> 以下 1.0.0 记录保持已发布 tag 的历史事实，不代表 v1.1.0 默认值。

## [1.0.0] - 2026-07-22

首个稳定发布版本。

### 架构

- GPU 推理统一为 `vllm[audio]==0.16.0` 原生 Speech-to-Text，不保留自建 Transformers
  服务后端、应用层固定 batcher 或旧 FastAPI 推理层。
- 新增 aiohttp CPU 网关：统一对外端口 8080，vLLM 仅监听本机 8081；`run.sh` 一次启动并
  管理两个进程。
- 新增 `src/config.py`，集中读取和校验所有网关系统配置，导出模块级 `settings`。

### 功能

- 支持 `/chinese_asr` Base64 JSON 和有限 multipart `/v1/audio/transcriptions`。
- 音频不超过 30 秒原字节直送；超过 30 秒固定切片，受控并发识别并顺序合并。
- 支持动态热词转 Qwen3-ASR Prompt 软偏置。
- `/chinese_asr` 返回段级时间边界；VAD、字级时间戳、CT 标点和 ForcedAligner
  未实现，错误开启相关开关时拒绝启动。

### 契约与可靠性

- 网关统一读取 `SERVED_MODEL_NAME`；健康检查返回版本与模型名。
- 零帧音频统一作为 `DECODE_FAILED`，不再返回成功空结果。
- 业务兼容接口保留 1000～1008 错误码；multipart 接口使用独立 JSON 错误结构，后端失败
  返回 502、超时返回 504、繁忙返回 503。
- CER go/no-go 强制参考覆盖全部输入且非空；缺失参考、空参考和零计分样本均失败。

### 模型与依赖

- 仅从 ModelScope 下载 `Qwen/Qwen3-ASR-0.6B`，固定 revision
  `4ce9cc728b473a5aedbe7b6e1ea45646316824dc`。
- 下载器校验 ModelScope 文件大小/SHA256，使用 `.part`、Linux 文件锁和原子 manifest；
  不允许同一目录静默混用仓库或 revision。
- 精确固定 vLLM 0.16.0、Transformers 4.57.6、aiohttp 3.13.3、soundfile 0.13.1、
  psutil 7.0.0。

### 性能

- 混合在线默认值为 `CHUNK_CONCURRENCY=3`、`LONG_CHUNKS_IN_FLIGHT=64`。
- A10 纯 90 秒测试中 `3/96` 达到 1537.09 audio_s/s，为吞吐优先候选；128 已越过拐点。

历史脚手架曾包含 SeACoParaformer 外壳、Transformers 单条推理及多项 TODO；这些均不是
v1.0.0 当前架构，详细现状以 README 与技术文档为准。
