# 性能优化实验台账

本文件是 `dev` 分支从 v2.0.0 演进到 v3.0.0 的追加式证据索引。策略定义、架构瓶颈、测试矩阵
和准入规则见[性能调优](性能调优.md)。未经目标 Linux/CUDA 实测的内容不得标记为“采纳”。

## 管理规则

- 实验 ID 使用 `PERF-<领域>-<三位序号>`，创建后不得复用；历史导入使用 `HIST-` 前缀。
- 状态只允许：`候选`、`就绪`、`测试中`、`采纳`、`拒绝`、`阻塞`。
- 一次只改变一个主要变量；多因素实验必须提前写明矩阵与交互假设。
- 每组至少预热 3 条、执行 3 轮，使用中位数决策，同时保留最差一轮。
- 拒绝和阻塞记录不删除；硬件、vLLM 或模型版本变化后可新建 ID 重新验证。
- 原始音频、模型、完整业务日志和敏感正文不进入 Git；提交去敏摘要、SHA256 和决策。
- 只有“采纳”且构成重要里程碑的提交创建带注释 tag，失败实验不打 tag。
